# 运维手册

> 版本：V1.0  
> 更新日期：2026-08-25

## 1. 日常巡检

### 1.1 每日检查清单
- [ ] 服务健康检查：`curl /api/v1/health`
- [ ] 数据库连接状态
- [ ] Redis 连接状态
- [ ] 磁盘空间使用率（<80%）
- [ ] 错误日志扫描
- [ ] 支付对账：核对微信商户平台与系统订单

### 1.2 每周检查清单
- [ ] 数据库备份验证
- [ ] 慢查询分析
- [ ] 安全日志审计
- [ ] 证书有效期检查

## 2. 订单管理

### 2.1 订单状态说明

| 状态 | 说明 | 用户可操作 |
|---|---|---|
| PENDING_PAYMENT | 待支付 | 取消、支付 |
| PAID | 已支付 | 取消（2小时前） |
| ACCEPTED | 已接单 | - |
| DEPARTED | 技师出发 | - |
| ARRIVED | 技师到达 | - |
| IN_SERVICE | 服务中 | 投诉 |
| COMPLETED | 已完成 | 评价、售后 |
| CANCELLED | 已取消 | - |
| EXPIRED | 已过期 | - |
| REJECTED | 已拒单 | - |

### 2.2 异常处理

**用户投诉**
1. 查看订单详情和状态日志
2. 联系技师了解情况
3. 根据情况决定退款或补偿

**技师拒单**
1. 查看拒单原因
2. 联系用户确认是否等待改派
3. 如需改派，使用管理端改派功能

**支付异常**
1. 检查支付单状态
2. 如微信已支付但系统未更新，手动触发支付通知处理
3. 联系微信支付客服核实

## 3. 技师管理

### 3.1 入驻审核
1. 审核资料完整性
2. 核实身份信息
3. 检查资质证书有效性
4. 通过或拒绝（附原因）

### 3.2 定价管理
- 管理员可为技师设置独立价格
- 未设置则使用项目基础价
- 价格变更不影响已创建订单

### 3.3 结算流程
1. 技师完成服务后自动生成收入明细
2. 管理员创建结算单
3. 线下转账后登记凭证
4. 技师查看结算记录

## 4. 数据管理

### 4.1 备份策略
- 全量备份：每日凌晨 3:00
- 保留策略：最近 7 天每日备份，最近 4 周每周备份

### 4.2 恢复演练
- 每月执行一次恢复演练
- 记录恢复时间和步骤

## 5. 安全管理

### 5.1 权限管理
- 最小权限原则
- 定期审计管理员权限
- 离职人员及时禁用账号

### 5.2 敏感数据
- 手机号脱敏显示
- 身份证号不存储原文
- 日志不记录敏感字段
- 支付密钥加密存储
